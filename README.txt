# Convite de Casamento — Isaias & Erika

## Estrutura

- index.html
- style.css
- script.js
- assets/foto-1.jpg
- assets/foto-2.jpg
- assets/music.mp3

## Como usar

1. Coloque a primeira foto em `assets/foto-1.jpg`.
2. Coloque a segunda foto em `assets/foto-2.jpg`.
3. Coloque a música em `assets/music.mp3`.
4. Abra `index.html` no navegador.

## Personalizações principais

No `index.html`:
- nomes
- versículo
- endereço
- link do Google Maps
- link de confirmação
- texto final

No `script.js`:
- data e horário do casamento
- link da lista de presentes

No `style.css`:
- cores
- fontes
- tamanhos
- espaçamentos
- efeitos

Observação:
Navegadores de celular normalmente bloqueiam reprodução automática de áudio. Por isso a música começa quando o convidado toca no botão ♫.
